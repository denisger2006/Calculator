Калькулятор обладает следующим функционалом:

1. Вычисление базовых арифметических выражений (с учётом приоритета операций);
2. Математические функции;
3. Справочное окно, содержащее информацию о константах и математических функциях,
также есть всплывающие подсказки для кнопок;
4. Отмена/возврат математических вычислений (именно вычислений, а не ввода с клавиатуры);
5. Просмотр и очистка истории вычислений.
   
Для парсинга арифметических выражений был использован код, 
вручную переписанный с Java на C#, взят с ютуб канала, ссылку на плейлист прикрепил.
